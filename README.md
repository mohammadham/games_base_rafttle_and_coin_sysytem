# ViserGo - پلتفرم ارائه خدمات به بازی‌سازان و بازیکنان

ViserGo یک وب اپلیکیشن جامع برای ارائه خدمات به بازی‌سازان و بازیکنان است. این پلتفرم دو مجموعه خدمت کلی را ارائه می‌دهد: سیستم فروش و استفاده از کوین‌های درون بازی و سیستم قرعه‌کشی محصولات، و همچنین مجموعه‌ای از APIها برای ارائه خدمات به بازی‌سازان.

## سناریوی کامل سیستم

این سیستم به بازی‌سازان و بازیکنان امکان می‌دهد تا از یک اکوسیستم یکپارچه برای مدیریت دارایی‌های دیجیتال و شرکت در رویدادهای مختلف بهره‌مند شوند.

**برای بازیکنان:**

*   **خرید کوین:** بازیکنان می‌توانند کوین‌های مختلف را با استفاده از درگاه‌های پرداخت متنوع (از جمله زرین‌پال) خریداری کنند.
*   **شرکت در قرعه‌کشی:** بازیکنان می‌توانند با استفاده از کوین‌های خود در قرعه‌کشی محصولات شرکت کنند و شانس خود را برای برنده شدن جوایز امتحان کنند.
*   **خرید محصولات:** بازیکنان می‌توانند محصولات دیجیتال (مانند آیتم‌های درون بازی) را با استفاده از کوین‌های خود خریداری کنند.
*   **سیستم تشویقی:** با شرکت در قرعه‌کشی‌ها، بازیکنان به عنوان جایزه، کوین‌های تشویقی دریافت می‌کنند.
*   **حساب کاربری یکپارچه:** بازیکنان می‌توانند با یک حساب کاربری در تمامی بازی‌هایی که از سیستم ViserGo استفاده می‌کنند، لاگین کرده و دارایی‌های خود را مدیریت کنند.

**برای بازی‌سازان:**

*   **API قدرتمند:** بازی‌سازان می‌توانند با استفاده از APIهای ViserGo، سیستم پرداخت درون‌برنامه‌ای خود را به راحتی پیاده‌سازی کنند.
*   **مدیریت کوین‌ها:** بازی‌سازان می‌توانند انواع مختلفی از کوین‌ها را با استفاده از کوین پایه در پنل مدیریت خود ایجاد و مدیریت کنند.
*   **مشاهده مبادلات:** بازی‌سازان می‌توانند لیست کاملی از مبادلات انجام شده در بازی‌های خود را مشاهده کنند.
*   **درخواست برداشت:** بازی‌سازان می‌توانند درآمد حاصل از فروش کوین‌ها و محصولات را به پول واقعی تبدیل و درخواست برداشت کنند.

## ساختار برنامه

این پروژه با استفاده از فریم‌ورک لاراول (نسخه 11) و پی‌اچ‌پی (نسخه 8.3) توسعه داده شده است. فرانت‌اند برنامه با استفاده از Blade و Vue.js پیاده‌سازی شده و از پایگاه داده MySQL استفاده می‌کند.

*   **`core`:** این پوشه شامل تمامی کدهای اصلی برنامه لاراول است.
    *   **`app`:** شامل مدل‌ها، کنترلرها، سرویس‌ها و سایر منطق برنامه.
    *   **`database`:** شامل مایگریشن‌ها، سیدرها و فکتوری‌ها.
    *   **`routes`:** شامل فایل‌های مربوط به مسیریابی برنامه.
    *   **`resources`:** شامل فایل‌های مربوط به نماها (Blade)، زبان‌ها و فایل‌های استاتیک (CSS, JS).
*   **`install`:** این پوشه شامل فایل‌های مربوط به سیستم نصب برنامه است.
*   **`.github`:** این پوشه شامل ورک‌فلوهای CI/CD برای استقرار خودکار برنامه است.

## لیست وظایف انجام شده

*   **بررسی و تکمیل پایگاه داده:** تمامی مایگریشن‌های لازم برای ایجاد ساختار پایگاه داده بر اساس فایل `database.sql` ایجاد شد.
*   **ایجاد و تکمیل سیدرها:** سیدرهای اصلی برای راه‌اندازی اولیه پایگاه داده ایجاد و زبان فارسی به عنوان زبان پیش‌فرض تنظیم شد.
*   **به‌روزرسانی سیستم نصب:** سیستم نصب برای استفاده از مایگریشن‌ها و سیدرها به جای فایل `sql` به‌روزرسانی شد.
*   **تکمیل درگاه پرداخت زرین‌پال:** درگاه پرداخت زرین‌پال به طور کامل پیاده‌سازی و تکمیل شد.
*   **بهبود امنیت:** سیاست‌های رمز عبور قوی‌تر در صفحه تغییر رمز عبور ادمین فعال شد.
*   **طراحی ورک‌فلو CI/CD:** یک ورک‌فلو کامل برای بیلد، تست و دیپلوی خودکار برنامه با استفاده از GitHub Actions طراحی شد.

## لیست وظایف آینده و بخش‌های نیاز به اصلاح

*   **تکمیل تست‌ها:** راه‌اندازی و تکمیل تست‌های واحد و ویژگی برای تمامی بخش‌های سیستم.
*   **بهبود تجربه کاربری:** بهبود رابط کاربری و تجربه کاربری در تمامی بخش‌های سیستم، به خصوص در پنل مدیریت.
*   **توسعه API:** اضافه کردن ویژگی‌های جدید به API برای ارائه خدمات بیشتر به بازی‌سازان.
*   **اضافه کردن درگاه‌های پرداخت جدید:** اضافه کردن درگاه‌های پرداخت ایرانی و بین‌المللی جدید.
*   **مستندات API:** ایجاد مستندات کامل و جامع برای APIهای سیستم.

## راهنمای راه‌اندازی سیستم

1.  **کلون کردن پروژه:**
    ```bash
    git clone https://github.com/your-username/your-repository.git
    ```
2.  **نصب وابستگی‌ها:**
    ```bash
    cd your-repository/core
    composer install
    ```
3.  **ایجاد فایل `.env`:**
    ```bash
    cp .env.example .env
    ```
4.  **تولید کلید برنامه:**
    ```bash
    php artisan key:generate
    ```
5.  **تنظیمات پایگاه داده:**
    در فایل `.env`، اطلاعات مربوط به پایگاه داده خود را وارد کنید.
6.  **اجرای مایگریشن‌ها و سیدرها:**
    ```bash
    php artisan migrate --seed
    ```
7.  **اجرای سرور توسعه:**
    ```bash
    php artisan serve
    ```

اکنون می‌توانید برنامه را در آدرس `http://localhost:8000` مشاهده کنید.
